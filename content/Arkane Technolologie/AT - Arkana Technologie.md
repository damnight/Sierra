# Übersicht
Hier werden Maschinen, Erfindungen und ähnliche Technologien hinreichend erklärt.

# Lokomotiven
Lokomotiven wurden von [[Richard Stephanson]] in [[Kulm]] run 1453 erfunden. Sie sind eine kulmination und synthese von mehreren anderen Technologien wie dem arkanen konduktor [[AM - Arkana Material#Orichalcum|Orichalcum]] und dem arkanen Kondensator [[AM - Arkana Material#Chardalyn|Chardalyn]]. 

## AKW - Arkana Kinetik Wandler
Der AKW ist die zentrale Erfindung für die Lokomotive und im allgemeinen für Antriebskraft. Mit dem AKW kann Magie in Kinetische Energie gewandelt werden. Dafür werden in einem stabilisierten [[AM - Arkana Material#Sirenen Glas|Sirenen Glas]] Gefäß [[AM - Arkana Material#Chardalyn|Chardalyns]] pulverisiert. Die entfaltete Magie wird in einer [[AM - Arkana Material#Orichalcum|Orichalcum]] Spule über einen [[AM - Arkana Material#Dimeritium|Dimeritium]] Kern geführt. Der Kern schwingt während dieser die magische Energie zerstreut. So wird Drehmoment aus Magie gewonnen, ohne dass eine Person das Weave bestimmen muss.
